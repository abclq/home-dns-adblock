Hermes 个人助理

个人自用的私人工具，不对外提供服务、不收集他人数据。

这是什么

一个运行在个人设备上的自动化助理程序。它通过 Google API 访问使用者本人的 Gmail、 Google 日历、Google Drive、Google 文档与表格，用于完成使用者自己交代的任务，例如：

  • 整理自己的收件箱、起草与发送邮件
  • 读取自己的日历安排、创建提醒事项
  • 在自己指定的 Drive 文件夹内读写文档与表格

程序不面向公众开放注册，也没有任何第三方用户。

数据怎么处理

所有数据都在使用者自己的设备上处理，不上传、不转售、不共享给任何第三方。 详见 隐私权政策。
