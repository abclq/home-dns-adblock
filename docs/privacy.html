隐私权政策

最后更新：2026 年 10 月 29 日

Hermes 个人助理（下称「本应用」）是仅供个人自用的私人工具，不面向公众提供服务。 本政策说明本应用如何访问和处理 Google 账号数据。

一、访问哪些数据

范围用途
Gmail（只读 / 修改 / 发送 / 设置）读取信件、整理标签、按使用者指令起草与发送邮件
Google 日历查看日程、创建或修改提醒与事件
Google Drive在使用者指定的文件夹内读写文件
Google 文档 / 表格读取与生成文档、表格
通讯录（只读）识别邮件往来对象，辅助整理收件箱

二、数据如何存储

OAuth 授权令牌与处理过程中产生的数据，只保存在使用者本人的设备上， 文件权限限制为使用者本人可读。不经过第三方服务器，不上传到云端数据库。

三、数据如何共享

不共享。本应用不出售、不出租、不以任何形式向第三方披露 Google 用户数据。 唯一的例外是：为完成使用者明确下达的指令（例如发送一封邮件）而必须调用 Google API 本身。

四、数据保留与删除

使用者可随时删除本机保存的令牌文件，删除后本应用立即失去访问权限。 也可以访问 Google 账号权限页 撤销本应用的授权。撤销后，本应用保存的令牌随即失效，不再保留任何数据访问能力。

五、Google API 服务用户数据政策

本应用对 Google API 所获信息的处理，遵守 Google API 服务用户数据政策， 包括其中的「有限使用（Limited Use）」要求。

六、未成年人

本应用不面向未成年人，也不会有意收集未成年人的信息。

七、政策变更

如本政策发生变动，将更新本页面并修改「最后更新」日期。
